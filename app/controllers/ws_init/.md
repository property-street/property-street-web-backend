## gen pool ds
```json
{
    [pending]: {
        _messages: bool,
        [message_list]: [{},...],
    }
}
```
### gen_pool initializer
- On initialization of the application, the user subscribes to the gen_pool using an id.
- The gen_pool initializer continues listening for data on the endpoint; when a data is received, the `data_channeler` function is called to channel the data.

### data_channeler
Handles incoming messages from the websocket client, publishes them to the Redis channel
