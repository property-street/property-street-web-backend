# Websocket connection initialization documentation

## client pend_pool hset key
<!-- This hset holds metadata of data that failed to reach the recipient(user_id) -->
```bash
pend_pool_{user_id}
```
### fields
- notifications: '[]' <!-- List of offloaded notification ids -->
- messages: '[]'  <!-- List of cached dialogue chat keys of a user-->


## register_channels
Initializes a pubsub instance, subscribes to a list of channels with their handlers registered.


## ws_reception_handler
Function that gets called when the websocket server receives a message from a websocket client.
