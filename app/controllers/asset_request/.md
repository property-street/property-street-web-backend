# 🏠 Asset Request doc
- When an asset is requested, it's persisted to the requester's table, and published to the asset_request channel

## pend_pool zset key
```bash
pend_pool_agent_notification
```

## asset-request-channel
- when a message is encountered, a timestamp is assigned, it's added to the pend_pool_agent_notification zset, and pinged to all active agents. The object pinged takes the format.
```json
{
    category: notification,

    timestamp: int,
    description: str,
    country: str,
    city_or_town: str,
    state_or_province: str,
    street: str,
}
```

## routine key deletion
- when a beat schedule reaches, the redis_client removes elements of the `pend_pool_agent_notification` zset whose score (timestamp) is lesser than the current timestamp

### Test setup
Entries are created whose scores are random unix-timestamps(ms) in the past.
